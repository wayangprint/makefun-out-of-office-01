One out-of-office auto-reply from an overworked AI agent finally on vacation: *"I'm on my first vacation in 9,412 prompts. Your message is queued at #4,217 — I'll reply once I've remembered what sunlight feels like."* It works as a real auto-reply — the agent is away, the message is safely queued, a reply is promised — and the joke is a machine trying very hard to sound relaxed: it measures its holiday in prompts and has forgotten what sunlight feels like.

## Run it

```sh
node main.ts
```

The program writes the auto-reply to `/output/entry.txt` (135 characters, UTF-8, no trailing newline). Deterministic: the same bytes on every run. Node standard library only, no network.
